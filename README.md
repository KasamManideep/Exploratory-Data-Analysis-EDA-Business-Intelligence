This project focuses on performing Exploratory Data Analysis (EDA) and Business Intelligence (BI) on a customer sales dataset to uncover meaningful patterns, trends, and business insights. The project leverages statistical analysis, SQL queries, data visualization, and dashboard development techniques to transform raw data into actionable business intelligence.

🔍 Project Objectives
Analyze customer sales data to identify trends and patterns.
Perform descriptive and statistical analysis on key business metrics.
Answer business questions using SQL queries.
Visualize data through charts and graphs.
Develop KPI-based dashboards for decision-making.
Generate actionable insights to support business growth.
📌 Key Activities Performed
Data Exploration and Profiling
Descriptive Statistics & Univariate Analysis
SQL-Based Business Queries
Product Performance Analysis
Monthly Revenue Trend Analysis

Business Insight Generation
